# 技术债务跟踪

显式记录被豁免（WAIVER）的技术债务。每一个条目都是"我们知道这有问题，但明确选择暂不修"。不应有未经记录的 workaround。

## 记录格式

每一条债务按以下格式记录：

```markdown
## TD-001：<简述>

- **日期**：YYYY-MM-DD
- **来源**：<关联的 PR / Issue / ADR 编号>
- **类别**：补丁式修复 / 过度防御 / 性能退化 / 架构妥协 / 其他
- **范围**：<涉及的文件/模块>
- **说明**：当前做了什么 workaround，为什么这样做
- **风险**：如果不修，最坏会发生什么
- **偿还计划**：<何时修 / 触发条件>
- **状态**：开放 / 已偿还
```
